# Práctica: Sistemas Expertos de Diagnóstico Médico

## Descripción
Este proyecto es un sistema experto basado en reglas diseñado para imitar el razonamiento humano en un diagnóstico médico simple. Utiliza la librería de Python `experta` para implementar un motor de inferencia mediante encadenamiento hacia adelante (forward chaining). El sistema evalúa conjuntos de síntomas (hechos) utilizando reglas lógicas para deducir un diagnóstico probable y brindar una recomendación médica.

## Requisitos previos
- Python 3.x
- Git
